Fotos dos clientes para os depoimentos (opcional).

Referenciadas em lib/content.ts no campo "avatar" de cada depoimento.
Atualmente os 3 depoimentos usam o mesmo arquivo (tr-logo.webp — o
medalhão/monograma TR), como identidade padrão enquanto não há fotos reais
dos clientes. Basta trocar o caminho no avatar de cada depoimento por uma
foto própria quando disponível.

Recomendado: imagem quadrada (1:1), ~200x200px, .webp. Se não existir, o
depoimento aparece sem foto (sem quebrar).
