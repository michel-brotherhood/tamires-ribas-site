Imagens dos projetos do portfólio.

Para cada projeto em lib/content.ts, coloque aqui as imagens referenciadas
(cover + gallery). Padrão de nome usado:

  {slug}-cover.webp
  {slug}-01.webp
  {slug}-02.webp
  ...

Ex.: casa-camboinhas-cover.webp, casa-camboinhas-01.webp...

Enquanto a imagem não existir, o site mostra um placeholder elegante no lugar
(SmartImage cuida disso) — nada quebra. Recomendado: .webp, ~1600-1800px de
largura, qualidade ~82 (foi assim que as fotos de clientes em /clientes foram
processadas — veja o histórico do repositório para o script usado).
